# Garden

Everything for the pixel-art garden background of the portfolio site.

- `final/`: the finished background. `garden-final-640x360.png` is the master to use in the site; `garden-final-1920x1080.png` is the same picture at exactly 3×. `FINAL.md` has the display rules and how each animation is placed and timed.
- `animations/waterfall/`: the waterfall sprite sheet (15 frames), a preview GIF and the script that builds it from the master.
- `animations/sakura/`: the sakura sway (72 frames). Use `sakura-sway-sheet-clean.png`; the folder also has the generator scripts, settings, a demo page and previews.
- `references/`: the original picture with signs, the sign-free style reference, the mockup, the layout guide and the image prompt used during the redesign.
- `references/concepts/`: concept images for the pages still to build (Projects workshop, Experience board and album, About album, Contact postcard, homepage directions, lighting modes).

- `animations/glow/`: workshop window glow and pier lantern flicker, with transparent sheets and a full-scene preview.

Still to animate: pond shimmer, fireflies, drifting petals, the cat.
